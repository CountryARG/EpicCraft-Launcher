# 🚀 EpicCraft Launcher

![Texto alternativo](app-icon.png)

El launcher oficial, ultra optimizado y ligero para EpicCraft.

## 🌟 Características
* ⚡ **Ultra ligero:** Rendimiento optimizado al máximo en todas las plataformas (~50 MB en macOS x64).
* 🔒 **Seguro y rápido:** Compilado de forma nativa para macOS y Windows.
* 🛠️ **Flags optimizados:** Motor Chromium ajustado para consumir el mínimo de memoria RAM.

## 🛠️ Instrucciones de Instalación

### En macOS:
1. Descarga el archivo `.dmg` correspondiente a tu Mac.
2. Haz doble clic para abrir el instalador y arrastra el ícono a **Aplicaciones**.
3. *Nota:* Si macOS te bloquea el inicio por no estar firmada, ve a `Ajustes del Sistema` > `Privacidad y seguridad` y selecciona **"Abrir de todos modos"**.

### En Windows:
1. Descarga el instalador `.exe`.
2. Ejecuta el archivo. Si Windows SmartScreen muestra una advertencia, haz clic en **"Más información"** -> **"Ejecutar de todos modos"**.
